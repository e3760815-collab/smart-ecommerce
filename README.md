# morrow — smart e-commerce

A responsive, front-end shopping experience for thoughtfully selected everyday goods. Built with plain HTML, CSS, and JavaScript—no build step or dependencies required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Features

- Responsive editorial-style storefront with product categories and search
- Product sorting by price or rating
- Personalized product picks that learn from cart and favorite activity
- Favorite products and shopping cart persisted with `localStorage`
- Cart quantity controls, subtotal, and free-shipping progress
- Newsletter signup interaction and accessible labels/controls

Product imagery is loaded from Unsplash. Checkout and newsletter submission are front-end demo interactions; no payment or email service is connected.
